## 约束

- 一个真实 Apple 账号只登记一个 profile；不同账号并行，同账号串行。
- 程序只打包一份 Python worker，按任务启动实例；不同账号不设并行数量上限，同账号保留独占执行。
- 用户主动点击才请求 Apple；开发验证使用合成数据与离线测试。
- 保留原 SRP / SSI / authx / Cookie 更新流程，不自动重试下单请求。
- 临时购买沿用原有确认方式；下单模板由用户点击“一键下单”授权，按保存的收货安排和总额上限自动核验并创建未付款订单。
- worker 通过私有管道接收密码/验证码，不通过命令行参数或日志传递。
- CLI 和桌面版分别适配交互；桌面版不解析中文终端输出来驱动业务。
- Windows 构建只能以 Windows CI/实机结果确认；macOS 成功不能代替 Windows 验证。
