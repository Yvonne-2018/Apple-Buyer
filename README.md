# DUO Killer · iPhone DUO 抢购辅助与 Apple 商城快速下单

面向 **iPhone DUO 抢购准备与快速下单** 的 Apple 中国在线商店辅助工具，支持 **macOS、Windows 和本地 Web**。提前配置账号、商品 SKU、购买数量和收货地址，在同一个界面完成登录检查、加入购物袋、结账确认、生成付款二维码和订单查询。

iPhone DUO launch assistant and Apple Store quick checkout tool for macOS, Windows and local Web. Built with Tauri, Rust, React and Python.

## 主要功能

| 功能 | 说明 |
| --- | --- |
| iPhone DUO 发售状态 | 无需登录，手动刷新官网返回的发售提示与商品可购买状态，方便开售前查看。未知状态不代表有货。 |
| 商品与数量预设 | 内置 iPhone DUO 各容量 / 配色及抛光布 SKU，支持自定义 SKU 和购买数量，减少临时填写。 |
| 快速下单 | 配置 SKU、数量和收货方式；自提从列表选择城市及多个门店，按顺序自动切换不可选门店。支持保存模板一键执行到支付宝付款码。 |
| 多账号独立运行 | 每个账号独立保存会话、设备信任和浏览器配置；不同账号可以并行操作，验证码与确认提示标明所属账号。 |
| 登录与设备信任 | 支持设备验证码、短信验证码，保存并复用有效的设备信任；需要重新认证时按提示完成登录。 |
| 配送与门店自提 | 可使用官网已有地址或本地快捷地址，支持选择官网返回的可取货门店。 |
| 支付与订单查询 | 展示支付宝付款二维码，扫码付款后查询订单，核对商品、数量及官网返回的订单状态。 |
| 执行进度与重试 | 窗口实时显示当前阶段与最近进度。页面读取、商店查询和门店搜索遇到临时网络错误时每 2 秒重试，最多 30 次；指定门店暂不可选时也会刷新查询。加购、结账写入和创建订单不会盲目重试，以免重复操作。 |

**DUO 使用流程：**提前配置账号与地址 → 刷新发售状态 → 选择 SKU 和数量 → 立即下单 → 核对并确认订单 → 扫码支付 → 查询订单。

“购买商品”的模板与临时购买均提供自提城市列表、当前城市门店多选和门店顺序调整。项目保存 [Apple 中国大陆官方目录](https://www.apple.com.cn/retail/storelist/) 中的 25 个城市、49 家直营店（2026-10-14），选择城市后仅显示该城市门店。原 SKU 按所选顺序尝试，全部不可取货后才尝试允许的替代 SKU。没有开启等待和替代时立即停止；开启等待后每轮从第一家门店重新查询。接口错误不会被当成无货切店，实际可取货状态及带签名的时段仍由官网实时确认。创建订单只提交一次；若结果不明，应先查询订单。目录更新方法与兼容说明见 [门店选项说明](docs/PICKUP_STORES.md)。

发售状态目前需要手动刷新，库存、价格与是否可购买以 Apple 实际返回为准；付款由本人扫码完成。

## 快速启动（Web）

**使用源码：**准备 Node.js 22.22+、pnpm 11.9、Rust stable、Python 3.10+（建议 3.12）。macOS 需 Xcode Command Line Tools，Windows 需 MSVC C++ Build Tools。具体安装见 [Tauri 前置要求](https://v2.tauri.app/zh-cn/start/prerequisites/)。

克隆仓库后启动：

```sh
git clone https://github.com/Jasper-zzq/iPhoneDuo.git
cd iPhoneDuo
pnpm install --frozen-lockfile
pnpm dev:web
```

程序自动准备 Python 环境、编译本地服务并打开浏览器。在启动终端按 **Ctrl+C** 退出服务；仅关闭网页不会退出服务。

**使用构建好的 Web 版：**macOS 双击 `local-web-release/启动.command`，Windows 双击 `local-web-release/start.cmd`。保留整个目录，无需安装开发环境。

## 下单模板：配置一次，执行到付款码

账号工作台 → **购买商品 → 下单模板**，点击“新建模板”或“从现有配置创建”。每个账号可以保存多个模板、复制、编辑、删除并设置默认模板，重启后保留。旧购买预设、快捷地址和临时购买入口继续可用。

提前配置 SKU、数量、**订单总额上限（人民币，含运费）**、收货方式、联系人及个人电子发票抬头：

- **送货上门**：填写模板地址，或填写指定官网地址的完整地区与街道；省市区用于结账配送查询。选择最低运费、最早送达或指定配送服务，并设置运费上限。官网地址在当前账号的实时地址列表中精确匹配，不缓存结账地址 ID。
- **门店自提**：从列表选择城市及一家或多家门店，用上移 / 下移调整优先顺序。选择最早可取时段或限定日期、每日时间范围。证件后四位可提前填写；官网要求但模板未提供时会停止并提示补齐，不临时弹出业务输入框。
- **缺货与替换**：默认仅买指定 SKU，可以开启持续等待到货。先按门店顺序尝试原 SKU；自提可填写同机型替代 SKU 白名单，在原 SKU 的所选门店全部不可取货后，按白名单次序逐个配置尝试所选门店。数量、总额上限保持不变。

可先保存草稿，补齐必填项后才能点击 **“按模板一键下单”**。点击即按当前保存版本创建未付款订单，购物袋仅保留本次目标商品，自动核对商品、数量、收货安排、支付宝和金额上限，正常流程直接显示付款二维码，不再逐步选择或确认。任务启动后的模板编辑只影响后续任务；旧配置导入后需要自行填写金额上限。

模板地址或服务无法匹配、未知运费、超价时停止。门店不可选或没有符合模板规则的取货时段时尝试下一家所选门店。最早送达仅在官网返回的日期可明确比较时自动选择；日期无法识别时提示修改配送规则。关闭等待到货且无替代 SKU 的模板在所选门店全部不可用时结束。

Apple 密码和临时验证码不保存在模板中。请提前完成账号登录准备；Apple 临时要求设备 / 短信验证或联系人验证时仍需处理。订单提交结果不明时先查询订单；二维码获取失败只重新获取已有订单的二维码，不重新创建订单。付款结果页显示模板名称和本次总耗时，实际速度受 Apple 响应、认证和库存影响。

## 最简单的购买流程：抛光布

以下为 Web 界面操作截图，使用模拟账号和订单；示例二维码不可付款，金额与状态以实际结账结果为准。

### 1. 正常登录

添加 Apple 账号，输入密码，按提示完成设备或短信验证码。已有账号先勾选，再点击“检查并使用所选账号”。

首次验证后自动保存 Apple 下发的设备信任，下次登录优先复用；只有信任失效或 Apple 再次要求时才输入验证码。设备信任与“保存密码”独立，移除账号会同时清除本机信任；旧 Python 配置导入时也会保留有效信任。

![添加并登录账号](docs/images/purchase-01-login.png)

### 2. 选择抛光布

在工作台的“预制商品”选择 **抛光布 · MLH74FE**，数量先设为 **1**，点击“立即下单”。

![选择抛光布与数量](docs/images/purchase-02-product.png)

### 3. 按提示继续结账

选择配送 / 自提、地址等并继续。核对商品、数量、收货信息和总金额，再点击“确认创建订单”，直到显示付款二维码。结账可能包含购物袋里已有的其他商品，请核对完整清单。

![核对商品与金额并确认订单](docs/images/purchase-03-confirm.png)

### 4. 扫码支付

在实际运行中，用支付宝扫描程序显示的二维码并完成付款。**下图仅为演示，请勿扫码支付。**

![付款二维码演示，不可付款](docs/images/purchase-04-payment.png)

### 5. 查询订单

打开“订单”，点击“查询订单”；也可点击付款码下方的“我已支付，查询订单”。确认商品、数量及官网返回的状态，只有待付款订单不代表付款成功。

![查询订单并确认状态](docs/images/purchase-05-orders.png)

**移除本地账号：**在账号选择页点击账号旁的“移除”，或进入工作台 → 账号与登录 → “移除账号”，确认后清除该账号在本机的数据和保存密码。未完成登录的账号也可移除；执行中的任务需先完成或取消。官网账号和订单、其他账号、通用预设不受影响。

## 预设 SKU 与快捷地址

**保存购买预设：**左侧打开“本地配置”，选择配置范围，在“预制商品”选择已有商品，或选“自定义 SKU”后填写 SKU 和数量，点击“保存购买预设”。

**扩充内置商品列表：**在 [`src/products.ts`](src/products.ts) 的 `presetProducts` 中，照抛光布条目的格式添加 `sku`、`name`、`price`，然后重新构建。`price` 仅作参考，支付金额以官网结账结果为准；本地保存自定义 SKU 不会自动新增下拉列表条目。

**配置快捷物流地址：**在“本地配置”填写姓名、通知邮箱、手机号、省市区和详细地址，点击“保存地址预设”。结账时选择“为我送货”，再选择使用本地快捷地址；仍可选择官网已有地址。

配置范围选“通用预设”时，只供之后添加的新账号继承；选择具体账号则只修改该账号。地址预设保存在本机，不会直接修改官网地址簿。

## 构建

在目标系统及对应架构上构建，不能直接把 Mac 产物拿到 Windows 使用。先准备上述开发环境。

### macOS

```sh
pnpm install --frozen-lockfile
pnpm worker:setup
pnpm worker:build
pnpm bundle
```

输出：`src-tauri/target/release/bundle/dmg/*.dmg`，以及 `src-tauri/target/release/bundle/macos/DUO Killer.app`。

当前构建使用本地临时签名（ad hoc），未配置 Developer ID 发行签名和公证。若首次打开提示无法验证开发者，确认来源可信后，先尝试打开一次，再到 **系统设置 → 隐私与安全性 → 仍要打开**，确认“打开”。此方法针对未认证开发者提示；不要忽略恶意软件或损坏警告。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

### Windows

安装 Visual Studio C++ Build Tools，勾选“使用 C++ 的桌面开发”，并安装 WebView2；详见 [Tauri 前置要求](https://v2.tauri.app/zh-cn/start/prerequisites/)。在 PowerShell 中进入项目目录，执行：

```powershell
pnpm install --frozen-lockfile
pnpm worker:setup
pnpm worker:build
pnpm bundle
```

输出：`src-tauri/target/release/bundle/nsis/*-setup.exe`。分享此安装程序即可，已包含 Python worker 与门店目录，安装后无需另装 Python、Node 或 Rust。当前没有 Windows 发行证书，系统可能显示未知发布者提示。

### GitHub 自动打包

在 [GitHub Actions](https://github.com/Yvonne-2018/iPhoneDuo/actions/workflows/build.yml) 中选择 **Desktop packages → Run workflow**，或推送 `v*` 标签。仅生成：

- **duo-killer-mac-arm64**：适用于 Mac M 系列芯片的 DMG。
- **duo-killer-win-x64**：适用于 Windows 64 位的 EXE 安装程序。

每个平台先执行 worker、Rust、界面测试，再构建安装包并检查内置 worker。Windows runner 还会静默安装，核对主程序和内置 worker。构建成功后在本次运行的 **Artifacts** 下载；GitHub 会将产物打成 ZIP，解压后使用里面的 DMG 或 EXE。产物保留 30 天。当前不构建 Intel Mac，不自动生成 Web 包，也不自动发布 GitHub Release。Web 工作流保留手动运行入口。

### 构建 Web 版

在 macOS 或 Windows 的项目目录执行：

```sh
pnpm install --frozen-lockfile
pnpm build:web
```

输出：`local-web-release/`，复制整个目录给相同系统和架构的电脑使用。项目也提供 [桌面构建 CI](.github/workflows/build.yml) 和 [Web 构建 CI](.github/workflows/local-web.yml)。

## 等待上架 / 到货（桌面 v4）

购买界面默认开启“等待上架 / 到货”。商品尚未开放、门店暂不可取货时，任务保留，每轮查询结束后 2 秒刷新，无固定库存重试次数上限；可随时取消。支持与同机型自动换配置一起使用，库存恢复后继续结账。程序需保持运行、联网且电脑不休眠。

等待只覆盖可识别的商品/库存不可用和可重试的读取失败；登录验证、接口格式变化、资料错误及不确定的加购/订单提交结果仍会要求处理，避免重复订单。SKU 尚未列出也可能代表输入错误，状态区会提示。

## 本地密码（桌面 v9）

v9 默认不读取或写入系统钥匙串。账号工作台提供“设置 / 修改本地密码”和“清除本地密码”，首次登录的密码提示也可勾选本地保存。密码存储在应用用户数据目录内对应账号的 `local-password.json`，不在安装包、源码目录或普通地址配置中。macOS 文件权限为 0600。该文件未加密；具备本机用户权限的程序仍可能读取，备份账号数据时也会包含它。

旧钥匙串密码不会自动迁移或删除，需要首次重新填写 Apple 账号密码。验证码及系统登录密码不会保存。清除本地密码不会注销已登录的 Apple 会话；移除账号时清除该账号本地数据。修改密码设置本身不向 Apple 发送验证请求。
